# elster-mcp

Let Claude check and file German tax data through ELSTER, using the official ERiC library on your own machine.

## What you get

- **Catch mistakes before ELSTER does.** Tax ID, IBAN and tax-number checks run offline with the same rules ELSTER uses.
- **Find your tax office in seconds.** List every Finanzamt per federal state and look one up by number.
- **Know your certificate is still good.** See when your ELSTER certificate expires, without opening the ELSTER portal.
- **Validate a return before you send it.** ERiC checks the XML locally and can write a preview PDF.
- **File safely.** Submissions are test-only by default. A real filing needs the operator flag and your explicit approval of that exact return.

## From install to first result

1. Download ERiC from the ELSTER developer area and extract the archive.
2. Register the server with Claude Code.
   ```bash
   claude mcp add elster -s user \
     -e ERIC_HOME=/path/to/ERiC-45.1.5.0/Darwin-universal \
     -e ELSTER_CERT_PATH=/path/to/your-certificate.pfx \
     -e ELSTER_CERT_PASSWORD_CMD="your-secret-manager command that prints the password" \
     -- uv run --directory /path/to/elster-mcp elster-mcp
   ```
3. Ask Claude to check your ELSTER setup and tell you when your certificate expires.

## Tools

| Tool | What it does | Contacts ELSTER |
|---|---|---|
| `elster_system_check` | ERiC loads, what is configured | no |
| `elster_check_tax_id` | Validate a tax ID (IdNr) | no |
| `elster_check_iban` | Validate an IBAN | no |
| `elster_check_tax_number` | Validate a 13-digit ELSTER tax number | no |
| `elster_convert_tax_number` | Tax number from a notice to ELSTER format | no |
| `elster_list_states` | Federal-state numbers | no |
| `elster_list_tax_offices` | Tax offices of one state | no |
| `elster_tax_office_info` | Details of one tax office | no |
| `elster_list_test_tax_offices` | Test tax offices for test filings | no |
| `elster_certificate_info` | Certificate validity, password never returned | no |
| `elster_validate_return` | Validate a return locally, optional preview PDF | no |
| `elster_submit_return` | Send a return, test mode by default | **yes** |

## Configuration

| Variable | Required | Meaning |
|---|---|---|
| `ERIC_HOME` | yes | Extracted ERiC platform folder (contains `lib/`) |
| `ELSTER_CERT_PATH` | for certificate and sending | Your `.pfx` certificate |
| `ELSTER_CERT_PASSWORD_CMD` | for certificate and sending | Command that prints the password (preferred) |
| `ELSTER_CERT_PASSWORD` | alternative | The password itself |
| `ELSTER_HERSTELLER_ID` | to validate or send returns | Your own Hersteller-ID, the ERiC sample ID 74931 is refused |
| `ELSTER_ALLOW_LIVE` | no | `1` allows real filings, off by default |
| `ELSTER_LOG_DIR` | no | ERiC log folder, default `~/.elster-mcp/logs` |

Neither is part of this repository. elster-mcp loads the wrapper from your own ERiC download at runtime, so you obtain ERiC, accept its licence yourself, and keep it on the current minimum version.
